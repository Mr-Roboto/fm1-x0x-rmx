# JUNO starting presets

64 original recipes inspired by classic Alpha/Juno textures, hoovers and breakage.
These are starting points voiced for this engine; they are not imported third-party banks.

In JUNO EDIT, turn PRESETS to browse. The number/name appear on screen; `*` means
the patch has been edited. SAVE retains the edited patch and its parent preset identity.
The knob wraps from 64 to 1. On other parts/screens it retains pattern selection.

Preset recall changes the 44 synth controls. Mixer, pan/sends and sequencer patterns
keep their current settings. Held chords reattack the selected patch envelope.
